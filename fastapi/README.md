## 초급 과정 한눈에 보기

| 장 | 주제 | 만드는 것 |
|:---:|---|---|
| 00 | 웹과 API 첫걸음 | 요청·응답, URL, JSON, 가상환경, 첫 서버 |
| 01 | 첫 API 만들기 | 주소 여러 개, 경로·쿼리 매개변수, `/docs` |
| 02 | 데이터 보내기 — POST | 회원 가입, 값 검사(`Field`), 커피 주문 |
| 03 | 메모장 API — CRUD | 만들기·읽기·고치기·지우기, 404 |
| 04 | 웹 페이지와 API | HTML 돌려주기, `fetch`, 동기·비동기 체험, 화면에서 POST |
| 05 | 메모장 웹 앱 | 3장 API + 4장 화면 = 완성된 메모장 |
| 06 | AI 맛보기 | AI 모델을 함수 하나로 → 예측 API + 예측 화면 |
| 07 | 미니 프로젝트 | 방명록 예시(파일 저장), 친구 폰에서 접속, 나만의 서비스 만들기 |
