# 05. 메모장 웹 앱

3장의 메모장 API 와 4장의 화면을 합쳐 진짜로 쓸 수 있는 메모장을 만들어요.

> 🧭 [초급 과정 처음으로](../README.md) · 교안: [FastAPI_초급교안.pdf](../../FastAPI_%EC%B4%88%EA%B8%89%EA%B5%90%EC%95%88.pdf)

| 파일 | 실행 (이 폴더에서) | 내용 |
|---|---|---|
| `memo_app.py + memo_page.html` | `uvicorn memo_app:app --reload` | 브라우저 http://127.0.0.1:8000 에서 메모 쓰기 · 고치기 · 지우기 |
| `연습문제_정답/정답_app.py` | (정답 폴더에서) uvicorn 정답_app:app --reload | 글자 수 표시 + [모두 지우기] |

연습문제 정답은 `연습문제_정답` 폴더에 있어요.
