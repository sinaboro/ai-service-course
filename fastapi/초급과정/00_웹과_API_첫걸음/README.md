# 00. 웹과 API 첫걸음

웹이 움직이는 원리(요청 · 응답)를 알고, 실습 환경을 준비해 첫 서버를 켜 봐요.

> 🧭 [초급 과정 처음으로](../README.md) · 교안: [FastAPI_초급교안.pdf](../../FastAPI_%EC%B4%88%EA%B8%89%EA%B5%90%EC%95%88.pdf)

| 파일 | 실행 (이 폴더에서) | 내용 |
|---|---|---|
| `ex01_json_basics.py` | `python ex01_json_basics.py` | JSON 글자 ↔ 파이썬 딕셔너리 |
| `ex02_python_warmup.py` | `python ex02_python_warmup.py` | FastAPI 에 나오는 파이썬 문법 미리보기 |
| `check_setup.py` | `python check_setup.py` | 파이썬 · 가상환경 · 패키지 · 포트 점검 |
| `ex03_first_server.py` | `uvicorn ex03_first_server:app --reload` | 첫 서버 → 브라우저로 http://127.0.0.1:8000 |

연습문제 정답은 `연습문제_정답` 폴더에 있어요.
